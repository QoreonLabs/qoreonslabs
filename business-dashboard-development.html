05Questions

Dashboard questions.

What people usually ask before we build a dashboard. Anything else, just ask.

Still unsure?Email support@qoreonlabs.com
Which tools and data sources can you connect?
Most tools with an API or an export: Shopify, WooCommerce, Stripe, Xero, QuickBooks, HubSpot, Google Sheets, Airtable and SQL databases such as PostgreSQL and MySQL. If a system has no API, we can usually work from a scheduled export or a shared spreadsheet.
Why not just use Power BI, Looker Studio or Tableau?
Sometimes you should, and we'll say so on the first call. Off-the-shelf BI tools are great when your data is already clean and someone on your team enjoys building reports. A custom dashboard makes more sense when the data needs real cleaning first, when people need to act on what they see (approve, reorder, assign), when you want it inside your own app or portal, or when per-seat licences add up.
How much does a custom dashboard cost?
Every project gets a fixed quote after a free 15-minute call, so you know the full price before anything starts. The main things that drive cost are how many data sources we connect, how messy that data is, and how many different views and roles you need.
How long does it take?
Most dashboards take 3 to 8 weeks depending on scope. You get a working preview every week, using your real data as soon as it's connected, so you can check the numbers long before launch.
Who can see our data?
Only the people you invite, and each person only sees what their role allows. We connect with read-only access wherever the tool supports it, keep passwords and keys on the server rather than in the browser, and host everything in accounts that you own.
Can we add new charts and metrics later?
Yes. You own the code and the accounts. Adding a new metric or view is usually a small job, and we offer simple monthly support if you'd like us to keep improving it. Or we can hand it over to your own developer with a walkthrough.
